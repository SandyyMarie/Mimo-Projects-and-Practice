# Express Projects

A collection of Express.js projects built while completing Mimo's Full-Stack and Back-End career certifications.

## Prerequisites

Make sure you have the following installed before running any projects:

- [Node.js](https://nodejs.org/en/download/) (v14+)
- [npm](https://www.npmjs.com/) (included with Node.js)

## How to Run

1. Navigate to the project folder:
```bash
    cd Express/ProjectNameHere
```

2. Install dependencies:
```bash
    npm install
```

3. Start the server:
```bash
    node app.js
```
    or
```bash
    node script.js
```
