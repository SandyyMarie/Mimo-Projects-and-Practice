# JavaScript Projects

A collection of JavaScript projects built while completing Mimo's Full-Stack and Front-End career certifications.

## Prerequisites

Make sure you have the following installed before running any projects:

- [Node.js](https://nodejs.org/en/download/) (v14+)
- [npm](https://www.npmjs.com/) (included with Node.js)

### Command-Line Projects

The following projects run in the terminal and require Node.js:

1. Navigate to the project folder:
```bash
    cd JavaScript/ProjectNameHere
```

2. Install dependencies:
```bash
    npm install
```

3. Run the script:
```bash
    node script.js
```

| Project | Dependencies |
|---|---|
| Blackjack | `@mimo-org/input` |
| Even or Odds | `@mimo-org/input` |
| Lightswitch | None |
| Task List | `@mimo-org/input` |
